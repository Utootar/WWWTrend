# ทำสื่อจากข่าว (Claude ทุก 2 วัน หลังรอบวิเคราะห์)

อ่าน `CLAUDE.md` ก่อน งานนี้คือทำ **ร่าง** สื่อ: ชุดภาพปัด + ภาพยาว + วิดีโอผู้ประกาศ จากข่าวและบทวิเคราะห์ล่าสุด
ห้ามโพสต์หรือเผยแพร่ที่ไหน ไฟล์อยู่ใน `media/` รอเจ้าของดู

## ขั้นตอน

0. เตรียมเครื่อง (ทำครั้งเดียว):
   `python -m pip install -q -r requirements.txt playwright numpy`
1. วันนี้ D = `TZ=Asia/Bangkok date +%F` หาไฟล์ข่าวล่าสุดใน `news/`
   - ถ้าไฟล์ล่าสุดเก่ากว่า D เกิน 3 วัน → **หยุด** ไม่ทำสื่อ จบงานพร้อมบรรทัดเดียวว่าข่าวค้างตั้งแต่วันไหน
   - ถ้า `media/D/` มีอยู่แล้ว → จบเลย
2. เลือกข่าว 3 ข่าวจาก `data/YYYY-MM/<ข่าวล่าสุด>.json`: เอา `importance = 3` ก่อน ไม่พอเติม 2 เลือกเรื่องที่ตรงกับหมวดหลักใน `memory/watchlist.md` หรือธีมใน `memory/themes.md`
3. หารายละเอียดเพิ่มต่อข่าว 2–3 ข้อ (`details`) จากข่าวอื่นใน `data/` ย้อนหลัง 14 วันที่พูดเรื่องเดียวกัน ทุกข้อต้องมี `source` และ `link` จากไฟล์ข่าว (ราคาใช้ `source: "ตารางราคาในไฟล์ข่าว"` ไม่ต้องมีลิงก์)
4. เอามุมมองจากบทวิเคราะห์ล่าสุดใน `analysis/` และ `memory/themes.md` (`views`) ข่าวละ 1–2 ข้อ ใส่ระดับความมั่นใจตามที่บทวิเคราะห์เขียน และ `from` = path ไฟล์ที่มา
   - ห้ามแต่งมุมมองใหม่เอง ถ้าบทวิเคราะห์ไม่ได้พูดเรื่องนั้น ใส่ `{"text":"ยังไม่มีมุมมองในบทวิเคราะห์เรื่องนี้","confidence":"—","from":"memory/themes.md"}`
   - ถ้าข่าวอยู่ในธีมของ `memory/themes.md` ใส่ `theme` (ชื่อ, ความเสี่ยงของธีม, หุ้น 3–4 ตัวพร้อม % จากตารางราคาหุ้นในธีมของไฟล์ข่าว)
5. เขียน `media/D/content.json` ตามรูปแบบของ `media/2026-10-20/content.json` ทุกช่อง รวม `say`/`caption` ของผู้ประกาศ
   - `say` เขียนชื่ออังกฤษเป็นคำอ่านไทย ตัวเลขเป็นคำไทย ทุกประโยคต้องมีในข้อเท็จจริงหรือมุมมองข้างบน
   - `intro`/`disclaimer`/`outro` ใช้ข้อความเดียวกับไฟล์ตัวอย่าง (เปลี่ยนแค่วันที่)
   - ตัวเลขทุกตัวต้องตรงกับไฟล์ข่าวหรือ `data/` ถ้าข่าวกับราคาขัดกัน ใช้ราคาจากตาราง และจดใน `sources.md`
6. `cd scripts && python make_media.py ../media/D/content.json --only poster` แล้วเปิดดูภาพ `slide-*.png` ทุกใบ ถ้ามีข้อความล้นหรือถูกตัด ให้ย่อ `what`/`details` แล้ววาดใหม่
   - **ไม่ต้องทำวิดีโอเอง** เสียงไทยต้องใช้ edge-tts ที่เครื่อง Claude ต่อไม่ได้ พอ push `content.json` แล้ว workflow `Render media video` จะทำ `video-D.mp4` ด้วยเสียงไทยแล้ว commit ให้เอง
7. เขียน `media/D/sources.md`: ตารางลิงก์ต้นทางทุกลิงก์ที่ใช้ · ข่าว ★★★ ที่ไม่ได้เลือก · ข้อที่ไม่แน่ใจหรือหาไม่เจอ
8. commit `media: D drafts` แล้ว push เข้า `main` (ชนให้ `git pull --rebase origin main` แล้ว push ใหม่)

## ห้าม

- ห้ามแต่งลิงก์ ห้ามเดาตัวเลข ห้ามใส่ข้อมูลจาก `memory/private.md`
- ห้ามสั่งซื้อ/ขาย ห้ามให้ราคาเป้าหมาย (บอกชื่อหุ้นในธีมได้)
- ห้ามแก้ไฟล์นอก `media/D/`
- ห้ามโพสต์ ห้ามเปิด PR
