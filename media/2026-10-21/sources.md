## ข้อที่ไม่แน่ใจหรือหาไม่เจอ

1. **ข่าวทองคำ**: ลิงก์ทั้งหมดเป็น Google News ยังไม่ได้เปิดต้นทางเช็ค ("62 ตัน", "เดือนที่ 10", "ต่ำสุดตั้งแต่ 2019" มาจากหัวข่าว) บทวิเคราะห์ก็บอกว่ายังไม่ได้เช็คต้นทาง
2. **ราคาหุ้น Tesla และ SpaceX**: ไม่มีในข้อมูลราคาของ repo (SpaceX ไม่ได้จดทะเบียน)
3. **ราคาเป็นของวันอังคาร 20 ต.ค.** ตามที่บทวิเคราะห์หมายเหตุไว้
4. **มุมธุรกิจ (ค่าเดินทางช่าง)** มาจากหัวข้อ "มุมธุรกิจเจ้าของ" ในบทวิเคราะห์ ไม่มีระดับความมั่นใจ จึงแสดงเป็นป้าย "บันทึก"
5. **เปิดบทความต้นทางไม่ได้** เครื่องนี้เข้าเว็บข่าวไม่ได้ รายละเอียดมาจากข่าวอื่นที่ repo เก็บไว้
6. **เสียงผู้ประกาศ**: เสียงไทย Neural (edge-tts, th-TH-PremwadeeNeural) ทำโดย GitHub Actions workflow `Render media video` คำพูดทุกประโยคมาจากข้อเท็จจริงและมุมมองในตารางด้านบน
