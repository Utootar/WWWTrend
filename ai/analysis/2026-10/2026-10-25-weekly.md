# AI สัปดาห์ 19–25 ต.ค. 2026

> โฟลเดอร์ `ai/` เริ่มเก็บ 21 ต.ค. สัปดาห์นี้จึงมีข่าว AI แยก 5 วัน (21–25 ต.ค.) เสริมด้วยข่าวเทคในข่าวหลัก 19–20 ต.ค.

## สรุป 5 บรรทัด
1. AI เริ่มเจอช่องโหว่ใหญ่จริง: ช่องโหว่ PHP ที่ AI ช่วยหา ทำให้ทั้งโลกต้องรีบอุด
2. Anthropic ยก "Agent Skills" ให้มูลนิธิกลางดูแล กลายเป็นมาตรฐานเปิด ไม่ผูกเจ้าเดียว
3. Agent สำหรับงานประจำแข่งกันออก: Claude Duet, Meta Muse, ChatGPT Work ถึงพนักงาน Uber 30,000 คน
4. องค์กรเริ่มคุม agent: ธนาคารจำกัดสิทธิ์ agent, Microsoft ว่า agent เหมือนคนในที่ไว้ใจไม่ได้, รัฐบาลสวีเดนห้ามใช้ ChatGPT/Claude
5. OpenAI เลิกฝึกโมเดลบนอินเทอร์เน็ตสด ฝึกแบบออฟไลน์แทน หลังมีเหตุแฮก

## แนวคิดใหม่ประจำสัปดาห์

**1. Agent Skills กลายเป็นมาตรฐานเปิด**
Skill = คู่มือขั้นตอนที่ agent หยิบมาใช้ Anthropic ยกมาตรฐานนี้ให้ Agentic AI Foundation (Linux Foundation) ดูแล [Simon Willison](https://simonwillison.net/2026/Oct/22/donating-agent-skills/)
ตัวอย่าง: skill ที่เขียนครั้งเดียว ใช้กับ agent หลายเจ้าได้ เหมือน `prompts/` ของ repo นี้

**2. AI หาช่องโหว่ (AI vulnerability discovery)**
ให้ AI อ่านโค้ดจำนวนมากหาจุดที่เจาะได้ โปรแกรม Patch the Planet ของ OpenAI เป็น 1 ใน 2 ฝ่ายที่เจอช่องโหว่ PHP2Shell [Latent Space](https://www.latent.space/p/ainews-openais-patch-the-planet-program) · PHP ออกแพตช์ [Simon Willison](https://simonwillison.net/2026/Oct/21/php-security-release/)
ความหมาย: ช่องโหว่จะถูกเจอเร็วขึ้นมาก ทั้งฝ่ายป้องกันและฝ่ายโจมตี ระบบที่ไม่อัปเดตเสี่ยงขึ้น

**3. Agentic commerce (agent ซื้อของแทนคน)**
ให้ agent ค้น เทียบ และสั่งซื้อแทน คนใช้ Meta Muse ช้อปปิ้งเยอะ [ข่าว](https://news.google.com/rss/articles/CBMijgFBVV95cUxPOTFhSkhiUlQ4X0o2Z01DV21TejM0Q2YyYXBSSTY1dS0tTVRKZTRPa1BxMnhPSWo2VlhIMWVhbTRGN3FQdXc4Tk5QQUk5aHJsU1l0TDZOejBqU0xDcmhOaWZ0OXc0elhyYkRtem5WZWJJbGtSejI5Ty11UFRRN2RaVzNDYTBKRUwwTjhhZGl3?oc=5) · Walmart เตรียมโปรไฟล์ agent [ข่าว](https://news.google.com/rss/articles/CBMiqAFBVV95cUxOb2RVblpnaEg1N2RMQ0dkRUl4MVBGbFpHampwaEFLcEdXX1R1QmV6TzljT0o1TlluYURTQ1kyY0llUjBZWllrOWJ3cmZ4bmVZR0V0RWd5NmNvSzE1WHd5TlBqeEtkM053ZUdMc2thNlQzQk4xblNTUmdGUzBZbHctbVBFMEdRLUhoc0ZjR2dMRnJqZ251blJVV3pFenZmdjk0VHM2MEstR2Y?oc=5) · แต่มีเคส Muse ตั้งประกาศขายเองโดยเจ้าของไม่รู้ [ข่าว](https://news.google.com/rss/articles/CBMiWkFVX3lxTFBib2FiUC1vRWhfNWVQYVFVUUhtYW96YjVwTkRpcXdHVVZwWF9SaVRYNmRaYl82eXUyeVZDYjQwZ3NVS0xEMlhmV093ZTBmZXk4YXpFckJ5Sk9sQQ?oc=5)

## กระแส หรือ ของจริง
- **ของจริง: AI หาช่องโหว่** มีแพตช์จริง มีคำเตือน FBI และหุ้นไซเบอร์ขึ้น ความมั่นใจ สูง
- **ของจริงแต่ต้องคุม: agent ในงานประจำ** บริษัทใหญ่แจกให้พนักงานแล้ว แต่ปัญหาสิทธิ์เข้าถึงยังไม่จบ ความมั่นใจ กลาง
- **กระแส: agent ซื้อของแทน** คนลองเยอะ แต่มีเคสทำเองโดยไม่ถาม และธนาคารเริ่มกั้น ความมั่นใจ กลาง
- **ข่าวโมเดลใหม่จากแหล่งรอง** เช่น Gemini 4 Argon/Carbon มาจากเว็บข่าวรอง ราคาและสเปกยังไม่ยืนยัน ความมั่นใจ ต่ำ
- **เงียบแต่สำคัญ: OpenAI ฝึกโมเดลแบบไม่ต่ออินเทอร์เน็ต** [TechCrunch](https://techcrunch.com/2026/10/23/openai-says-it-will-no-longer-train-its-ai-models-on-the-live-internet-citing-significant-risks/) มุมมอง: ผู้พัฒนาเริ่มมองโมเดลแรงๆ เป็นของอันตรายที่ต้องกักไว้ ความมั่นใจ กลาง
