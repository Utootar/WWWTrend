# AI สัปดาห์ 26 ต.ค.–1 พ.ย. 2026

> ข่าว AI แยกครบ 7 วัน (26 ต.ค.–1 พ.ย.) เสริมด้วยข่าวเทคในข่าวหลัก ไม่ใช่คำแนะนำการลงทุน

## สรุป 5 บรรทัด
1. เครื่องมือ AI ถูกใช้เป็นช่องโจมตี: ส่วนขยาย Claude Code ปลอมบน Cursor Marketplace ฝังประตูหลัง (backdoor) เกือบ 12 ชม. คนติดตั้งได้ถึง 5,000 คน
2. คีย์ AI API ก็เป็นเป้า: Northflank ถูกเจาะ คีย์ AI ของลูกค้าถูกเอาไปใช้ ต้องเปลี่ยนคีย์ทั้งหมด
3. โมเดลใหม่: GPT-6.1 Terra (เร็ว ถูก เน้นใช้คอมพิวเตอร์แทนคน) · Gemini 4 Carbon (ขึ้นอันดับ 1 การทดสอบอิสระ ให้ฝ่ายป้องกันไซเบอร์ใช้ก่อน) · Microsoft MAI
4. Agent ถูกใช้โจมตีจริง: Chainalysis ถูกเจาะด้วย "offensive agentic techniques" และแฮกเกอร์จีนใช้ ARTEX
5. เงินและการใช้จริงเริ่มสะดุด: OpenAI ลดเป้าระดมทุนเหลือ ~$20B · DoorDash ได้ออเดอร์จาก agent ภายนอกแค่หลักร้อย · Anthropic ยื่น S-1 เข้า Nasdaq
