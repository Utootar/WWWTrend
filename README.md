# WWWTrend

สรุปข่าวและแนวโน้ม: หุ้นสหรัฐ · เศรษฐกิจโลก · น้ำมัน · ทอง · เทคโนโลยี · การแพทย์ + เรดาร์ของที่กำลังจะโต

**เริ่มอ่านที่ [LATEST.md](LATEST.md)**

## อ่านอะไรได้บ้าง

| ไฟล์ | คืออะไร | ออกเมื่อไหร่ |
|---|---|---|
| `news/` | ข่าวย่อภาษาไทย ทุกข่าวมีลิงก์ต้นทาง + ตารางราคา | ทุกวัน ราว 06:00 |
| `analysis/…-2day.md` | Claude วิเคราะห์ 2 วันล่าสุด | ทุก 2 วัน |
| `analysis/…-weekly.md` | วิเคราะห์ลึกทั้งสัปดาห์ + เรดาร์ + โอกาสธุรกิจ | เช้าวันอาทิตย์ |

ดาวหน้าข่าว: ★★★ สำคัญมาก · ★★ น่าสนใจ · ★ ทั่วไป

## ทำงานยังไง

1. ทุกเช้า GitHub ดึงข่าวจาก RSS กับราคาจาก Yahoo Finance
2. โมเดลฟรี (Gemini หลัก, OpenRouter สำรอง) ย่อข่าวเป็นไทย จัดความสำคัญ **แต่ไม่ให้ความเห็น**
3. Claude อ่านข่าวที่ย่อแล้วมาวิเคราะห์ตามรอบ

ข่าวย่อโดยโมเดลฟรีอาจผิดได้ ตัวเลขสำคัญให้กดลิงก์เช็คต้นทางก่อน บทวิเคราะห์ไม่ใช่คำแนะนำการลงทุน

## ปรับแต่ง

- เพิ่ม/ลดหัวข้อหรือแหล่งข่าว: บอก Claude หรือแก้ `config/sources.yaml`
- กดรันเก็บข่าวเองนอกเวลา: แท็บ **Actions** → **Daily news collect** → **Run workflow**
- คีย์ API อยู่ใน Settings → Secrets and variables → Actions (`GEMINI_API_KEY`, `OPENROUTER_API_KEY`)

กติกาเต็มสำหรับผู้ช่วยอยู่ใน [CLAUDE.md](CLAUDE.md)
