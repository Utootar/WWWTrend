**เริ่มอ่านที่ [LATEST.md](LATEST.md)** · ข่าว AI ที่ [ai/LATEST.md](ai/LATEST.md)

## อ่านอะไรได้บ้าง

| ที่ | คืออะไร | ออกเมื่อไหร่ |
|---|---|---|
| `news/` | ข่าวย่อรายวัน ทุกข่าวมีลิงก์ต้นทาง + ตารางราคา | ทุกเช้า (ราว 07:30–10:30) |
| `analysis/…-2day.md` | Claude วิเคราะห์ 2 วันล่าสุด | วันเว้นวัน |
| `analysis/…-weekly.md` | วิเคราะห์ลึกทั้งสัปดาห์ + เรดาร์ + โอกาสธุรกิจ | วันอาทิตย์ |
| `ai/` | ข่าว AI แยก + สรุป AI รายสัปดาห์ + คู่มือแนวคิด | ทุกเช้า / อาทิตย์ |
| `media/` | ร่างภาพปัด คลิป และลิงก์ต้นทาง รอเจ้าของดู | ทุก 2 วัน |

## สื่อร่าง (`media/วันที่/`)

| ไฟล์ | คืออะไร |
|---|---|
| `slide-…-1…5.png` | ภาพปัด 5 ใบ: ปก · ข่าวละ 1 ใบ · ราคาและจับตาต่อ |
| `infographic-….png` | ภาพยาวใบเดียว เนื้อหาเดียวกัน |
| `video-….mp4` | คลิปแนวนอน 16:9 (YouTube/Facebook) ผู้ประกาศหญิงพูดข่าวเสียงไทย จอใหญ่ซ้ายโชว์กราฟิกข่าว แถบหัวข่าว + ซับด้านล่าง |
| `video-…-tiktok.mp4` | คลิปเดียวกันแนวตั้ง 9:16 สำหรับ TikTok/Reels (จออยู่บน ผู้ประกาศอยู่ล่าง เว้นขอบล่างให้ปุ่มของแอป) |
| `sources.md` | ลิงก์ต้นทางทุกข้อ + ข้อที่ยังไม่แน่ใจ |

แต่ละข่าวแยกชัด: เกิดอะไรขึ้น (ข้อเท็จจริง + ลิงก์) · ความเป็นมา · **มุมมองจากบทวิเคราะห์** (กล่องเส้นประ บอกความมั่นใจ) · หุ้นในธีม
รูปประกอบเป็นภาพ AI จาก Canva (มีป้ายกำกับ) ผู้ประกาศเป็นตัวละครสมมติ ไม่โพสต์ที่ไหนเอง

## ทำงานยังไง

1. ทุกเช้า GitHub ดึงข่าวจาก RSS กับราคาจาก Yahoo Finance (ข่าว AI ดึงแยกอีกรอบ)
2. โมเดลฟรี (Gemini หลัก, OpenRouter สำรอง) ย่อข่าวเป็นไทย จัดความสำคัญ **แต่ไม่ให้ความเห็น** ข่าวที่ย่อพลาด Claude Haiku ซ่อมให้ และตรวจข่าวที่ย่อแล้วเทียบกับต้นทาง ข้อไหนผิดแก้ให้ (มีป้าย "แก้โดย Claude")
3. Claude วิเคราะห์ตามรอบ: Sonnet วันเว้นวัน · Opus วันอาทิตย์ (รวมสรุป AI)
4. ทุก 2 วัน Claude เลือก 3 ข่าวเด่น ทำภาพปัด แล้ว GitHub ทำคลิปเสียงไทยให้เอง

| เวลา (ไทย) | ใคร | งาน |
|---|---|---|
| 04:17 | GitHub Actions | เก็บข่าวหลัก + ราคา (`collect.yml`) |
| 05:47 | GitHub Actions | เก็บข่าว AI (`ai-collect.yml`) |
| 09:47 | Claude Haiku | ซ่อมข่าวที่ย่อไม่สำเร็จ + ตรวจแก้ข่าวที่ย่อผิด |
| 10:12 วันเว้นวัน | Claude Sonnet | วิเคราะห์ 2 วัน |
| 10:42 อาทิตย์ | Claude Opus | วิเคราะห์ลึก + เรดาร์ + สรุป AI |
| 11:07 ทุก 2 วัน | Claude + GitHub | ภาพปัด → คลิป (`media-video.yml`) |

GitHub มักเริ่มรอบตั้งเวลาช้ากว่ากำหนด 1–4 ชั่วโมง คลิปหน้าคนจริงใช้ Wav2Lip (ขยับปากตามเสียง) + กระพริบตา/ขยับหัว (`scripts/media_face.py`) รันบนเครื่องฟรีของ GitHub

ข่าวย่อโดยโมเดลฟรีอาจผิดได้ ตัวเลขสำคัญให้กดลิงก์เช็คต้นทางก่อน บทวิเคราะห์และสื่อไม่ใช่คำแนะนำการลงทุน

## ปรับแต่ง

- เพิ่ม/ลดแหล่งข่าว: บอก Claude หรือแก้ `config/sources.yaml` (ข่าวหลัก) · `config/ai/sources.yaml` (ข่าว AI)
- แก้ข้อความหรือตัวเลขในสื่อ: แก้ `media/วันที่/content.json` แล้ว push GitHub จะทำคลิปใหม่ให้เอง
- เปลี่ยนหน้าผู้ประกาศ: แทนไฟล์ `assets/anchor.jpg` (รูปตรงหน้า เห็นไหล่) และทำ `assets/anchor-alpha.png` ใหม่ (ขาว = ตัวคน ดำ = พื้นหลัง) · เปลี่ยนเสียง: ตัวแปร `MEDIA_VOICE` ใน `scripts/make_media.py`
- กดรันเองนอกเวลา: แท็บ **Actions** → เลือก **Daily news collect** / **AI news collect** / **Render media video** → **Run workflow**
- คีย์ API อยู่ใน Settings → Secrets and variables → Actions (`GEMINI`, `OPENROUTER`, `ANTHROPIC`, `CLAUDE_CODE_OAUTH_TOKEN`) ห้ามวางคีย์ในแชทหรือในไฟล์
